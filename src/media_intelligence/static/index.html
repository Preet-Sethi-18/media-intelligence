This tool reads news articles, Hacker News threads and Mastodon posts, finds the people, organisations, places and topics in them, and records how they are connected, with the sentence each connection came from. This page shows what is in the database right now.

Sources the crawler uses

Set in config/sources.toml. To crawl other pages, change the seeds there and run the pipeline again.

Pipeline runs

Type a name to see what it is connected to. Each dot is a person, organisation, place or topic; each line is a connection found in the text. Coloured, labelled lines say how they are connected (acquired, sanctioned, attacked, …). Click a line to read the sentence it came from; click a dot to explore from there.

Entities connected to the most different other entities. "Connections" counts distinct neighbours; "Kinds of connection" counts different relation types. Broad places and topics rank high because they appear next to everything. Click a name to explore it.

Connections that are new since a moment in time, or that grew a lot (at least 3 more web pages and at least 50 % more than before). Pick the moment below; by default it is the start of the latest pipeline run. Click a row to read the evidence.

Runs the whole pipeline: crawl the seed pages in the config with Crawl4AI → clean the text → find entities and connections → save them to the database. It takes several minutes (Hacker News asks for 30 seconds between pages). When it finishes, the other pages show the new data.

Database: . A database built with older extraction rules cannot be extended; start the server with a new MI_DATABASE_PATH (the default data/ one is fine).
